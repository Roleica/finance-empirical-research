# 候选深化与经济解释

先写问题、目标量（谁在何时相对什么变化）、数据支持、样本/变量定义与解释强度，再选方法。方法不按显著性竞选；使用当前权威方法文档核对实现与假设，不从记忆编造 API。

| 数据/问题证据 | 可考虑路线及核验点 |
| --- | --- |
| 连续结果、条件均值、面板 | OLS/固定效应；函数形式、组内变异、聚类层级、缺失与支持 |
| 非负结果、乘法条件均值、零值 | PPML 等；不要求整数；分离、收敛、稳健方差、固定效应和尺度 |
| 二元/比例/截断/持续时间 | 相应响应模型、边际效应与支持，不全部硬塞 OLS |
| 可辩护政策时点和比较组 | DID/事件研究；批次、预期、平行趋势、异质处理效应、样本构成；预趋势不显著不证明假设 |
| 外生工具/断点/可构建对照 | IV/RD/合成控制等；排除限制、弱工具、操纵/连续性、支持条件 |
| 预测/高维结构 | 时间/实体适当切分、嵌套验证和泄漏检查，区别预测与因果 |

DID 是设计，OLS/PPML 是估计工具，不是互斥按钮。表格不是封闭方法菜单。无识别条件可完成有价值的描述探索，但加控制或滞后不自动解决内生性。

## 深化项目逐项判断

描述性（样本、缺失、分布、支持）；基准及完整规格；机制和替代解释；调节/异质性；中介；稳健性；内生性/识别；诊断/敏感性；经济量级。逐项记录适用、不适用或数据不足及原因。

- 机制代理的相关性不证明机制；中介不能只靠逐步显著或系数下降。说明时序、混杂假设、处理后控制、非线性/交互；直接/间接/总效应是否同一目标量、样本及控制。不同方程口径的乘积比例不是自动可比的中介份额；总效应近零、符号抵消时尤其不能宣传份额。
- 异质性检验组间差异/交互，不用“一组显著另一组不显著”代替差异显著，保留多重检验与样本支持。
- 稳健性围绕测量、样本、模型和识别的具体威胁，不为星号无理由变换。保留各口径及失败。
- 标准误匹配抽样/冲击/处理分配层级；少聚类、序列/截面相关、影响点、共线和分离需诊断，必要时用适当有限样本推断。

## 量级与选择后验证

给原单位、单位变化、现实可行变化（如 IQR）、预测结果变化、参照基准和区间；标准差标准化不是经济价值。区别对数/水平、百分数/百分点及非线性边际效应。基准近零或单位未核时说明不可解释，不设通用“系数够大发论文”的阈值。

如可用，探索前保留适当时间/实体分离的确认样本，记录是否被查看；预处理/调参不得泄漏。全数据已探索时，没有新数据就仍属探索，稳健性不等于独立验证。再挑确认集最佳模型会消耗确认地位；新探索另轮登记。历史使用不明标 unknown。

独立审核读取规格、原始/加工抽查、完整结果及代码，复算关键估计和量级；报告证据及无法判断项。代码/数据错误修复后，全部依赖结果失效并重跑受影响部分，不只修摘要。
