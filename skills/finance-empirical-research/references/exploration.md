# 全量合理空间与执行

根据全部字典建立变量角色：标识、时间、测量、分类、构成项、派生指标、候选结果/解释/控制/分组/机制。角色可多重；不得将 ID 当连续处理变量，或把总额与构成项的算术恒等式当独立经济发现。

版本化 `space.json` 记录输入指纹、变量全集与别名、关系家族、生成规则、有限参数范围、适用性/排除理由、预算和未覆盖类别。逐项评估：

1. 同层及可连接跨源的方向性变量对，区别描述相关/预测/解释。
2. 多解释变量、合理控制集合、分类与固定效应；不把所有变量当控制，区分处理前混杂、后处理和碰撞变量。
3. 同期/滞后/增长率/差分/累计效应与时间窗；核查发布时间，避免前视。
4. 可解释变换、非线性、交互、调节、异质性、机制路径；不因简单线性不显著略去。
5. 跨层汇总/暴露/连接与不同层级关系；无法连接也登记原因。
6. 数据支持的识别设计和估计器组合；没有政策冲击不凭空造 DID，没有有效工具不硬做 IV。

每个家族登记具体生成语法、集合/范围、推导总数及不适用项。边界由经济意义、时间支持、识别与可估计性确定，不从结果倒推；资源只能影响批次顺序，不能变成“无意义”的理由。无限阶交互/无限变换不能字面穷尽，明确本轮边界及扩展入口。新增合理关系生成新版本，保留原空间。

为避免“挑几类代表模型”冒充全量，从测量变量全集独立生成方向性变量对检查表，逐对链接已登记规格或给出具体不适用/待扩展原因。总额与构成项存在恒等式，不代表构成项之间也都是恒等式；共享分母/分子的机械关系单独标记。再对高阶家族的生成规则做同样遗漏审查。试验预算允许只执行一个公开子空间，但不得因此将未覆盖的合理关系改成不适用，也不得宣称当前文件所有合理关系均完成。

筛选前安排覆盖审核：给审核者变量目录、连接图与规则，让其找漏掉的数据、家族和过度排除；不要只给模型计数。空间充分性是审查结论，不是机器保证。

## 执行与计数

先展开或可重建分片保存 `specs.jsonl`；每条有唯一稳定 ID、space_version、数据/样本/变换/代码指纹及全部选项。预先计数与列组合示例，小型冒烟检查后运行全部登记项，不只存成功模型。

状态：pending、running、succeeded、failed、blocked、not_applicable、stale。不适用需具体证据；不得从分母静默删除。中断的 running 核查进程与产物后更新。每批一个合并者，各 worker 独立分片，合并检查 ID 冲突；完成标记原子写入。尝试史追加，不能覆盖失败美化成功率。

分开报告：语义家族审查覆盖；生成规格处置计数；成功估计数/可执行规格数。列失败、阻塞、待运行和过期数，部分只称部分。`scripts/ledger.py coverage` 只检查当前规格与结果一一对应，不证明生成器穷举了全部合理研究。

## 全量结果与选择

保存全部主要参数或完整系数表，n、实体/时间/聚类数、SE/CI/p、估计器/协方差选项、收敛/共线/分离/样本流失、效果尺度、代码及日志。计算错误不等于“无效应”。选择有家族与假设依据的多重检验方法，保存原始/调整值、家族分母和失败处理，不按结果拆家族。BH 等不解决所有依赖、选择后推断与因果问题。

一个规格可能检验多个系数或联合假设：交互、二次项、多个解释变量的发现若被用于筛选，应进入登记的检验家族。仅调整每个模型第一个系数，不能称全部被考察假设已经校正。

按先登记标准筛候选，综合数据可信度、实质问题、量级/区间、稳定性、识别前景及重复性。可以排序，全量台账不删除；不显著、反向、失败均可检索。记录候选为何进出、用过哪些结果，不能将筛选后的显著性当预先假设验证。
