# 两层学术报告与证据交付

在撰写、更新、审核报告前完整读本文件。报告是可独立阅读的研究论证，不是任务日志；完整机器可读结果与代码仍是证据来源。结构标准化，模型、结论和篇幅不硬编码。不因要写报告而扩大本轮分析、检索或外部发布授权。

## 阶段与产物

| 实际阶段 | 交付 |
| --- | --- |
| 仅规划/数据理解 | 对应阶段报告；无估计时不写发现或虚构回归表 |
| 已进入探索，不论是否跑完 | 全量探索总报告；未跑完标题/摘要注明“阶段性，未完成全量执行” |
| 已对候选进行深化 | 每个研究问题一份专题实证报告；未完成部分标明，不把不同问题硬合成一篇论文 |
| 无合格候选或深化被否定 | 总报告保留结论；已有专题保留为不支持/证据不足版本，不删除失败方向 |
| 仅报告既有结果 | 先核对证据与使用史；不擅自重跑、补文献或补造缺失章节 |

全流程交付包括已有的两层报告与共同证据包。不要求先有显著结果才能成文。总报告是研究地图，不宣称单一中心贡献；专题围绕一个问题形成连贯论证。

## 第一层：全量探索总报告

以 [探索报告模板](../assets/exploration-report.md) 为起点，按实际范围调整。正文包括：

1. 摘要：范围、数据覆盖、实际执行情况、主要模式及关键不确定性。
2. 数据与可连接关系：来源、时间/层级、变量族、连接键及质量、无法连接或含义未明的部分。
3. 探索设计：有限合理空间、生成规则/版本、方法/样本/变换、多变量/跨源/时间覆盖及排除理由。分别审核空间充分性与执行覆盖。
4. 执行与整体结果：分开报告规划规格数、已尝试数、成功、失败、阻塞、未执行、合理不适用和过期数；明确状态是否互斥及分母。显著性检验数不等于模型数。报告方向、量级、不确定性和跨规格分布，而非只列最佳结果。
5. 多重检验与筛选：检验族、原始/调整后推断、缺失推断与失败规格的处理、候选纳入/未纳入理由、样本使用史和选择后局限。
6. 候选地图与研究边界：问题、数据、方法、结果/专题链接、证据强度、状态及争议。没有候选也记录；未完成项是事实，不自动变为新任务。

同一证据被多个方向引用不是独立发现；不同单位/目标量不可直接混合平均系数。大规模完整表放附件或索引，总报告给分布与可检索入口，不把十万规格塞进正文。

## 第二层：专题实证报告

以 [专题报告模板](../assets/study-report.md) 为起点。默认结构：标题与摘要；引言（问题、经济意义及已核验文献关系）；经济逻辑与研究预期；数据/变量/描述统计；研究设计；主要结果；稳健性与识别讨论；机制和拓展；讨论与结论；参考文献及附录。

- 针对实际研究类型调整章节。机制、调节、中介、异质性、内生性等逐项评估适用性，实施适用项；其余在方法覆盖表中标“不适用/数据不足/未执行”并给理由，不写空泛证明。
- 区分事前预期、探索后形成的解释和真正独立的确认分析。学术叙述顺序不等于执行历史，不把探索后假设伪装成事前提出。只具相关性证据时，标题、摘要和结论均使用对应语气。
- 写清模型公式、目标量、变量和单位、样本筛选、控制、固定效应、权重、聚类/推断、识别假设及选择理由。模型选择不能归结为“这一版显著”。
- 解释主要系数的现实变化量、基准及区间；保留重要反向、不显著和敏感结果。无显著性不是无效应的证明。机制代理不等于机制识别，不将口径不一致的中介方程比例写成统一分解份额。
- 文献段落只写已具证据的内容。未检索/未核读时明确状态，不为成文补造引用或宣称首次发现。文献核验按 [literature.md](literature.md)，统计解释按 [inference.md](inference.md)。

## 表图、文件和溯源

默认保留 Markdown 或 LaTeX 可编辑源稿。用户指定格式优先；完整报告在环境支持时同时导出可编辑 DOCX 与阅读 PDF，检查渲染、公式、分页和表格；无法导出则交付源稿并注明未生成格式，不擅自安装依赖或把改后缀当转换。不同格式必须来自同一核验版本，不分别改数值。

建议 `reports/exploration.md`、`reports/studies/<study_id>/report.md`；表图和附录随报告存放，完整运行结果保留原位。`START.md` 只链接报告和定向查询，不自动加载全文。报告目录为每项记录 id、层级、问题、主题/变量/方法、阶段、状态、版本、路径和来源 id；可并入现有候选目录，避免另建管理系统。

每份报告保存精简证据映射（如 `evidence-map.jsonl`）：报告/版本、段落或论断 id、表图/单元格位置、规格与运行 id、结果文件/记录/字段、输入版本、生成代码/命令、单位/换算/显示精度、核验状态。相同来源可引用公共记录，无须重复全部元数据。正文每个实质性数值（含摘要、百分比、样本数）均可追溯；计算值同时记录公式和原始数值。路径/内容指纹不符时标过期，不只修改文字。

回归表以可理解的变量名配原变量映射；注明因变量、系数与标准误/区间、样本量、控制项、固定效应、权重和聚类层级/数量。拟合指标按模型适用性报告，不强求所有模型都有 R²。注明星号阈值、原始或调整后 p 值及检验族。描述表交代有效样本、缺失、单位和分布；图有轴/单位、区间与样本说明。表图说明应可独立读懂，正文讨论核心内容，全部附表通过索引可找。

## 报告审核与完成标准

沿用现有审核角色，不额外开常驻团队。交付前让审核者依据报告、证据映射、完整结果和必要代码检查：

1. 章节与实际阶段是否匹配；探索和确认、未执行和不适用是否混淆。
2. 所有正文数值和表图是否能定位来源；用项目脚本对齐数字、单位、样本与显示精度，人工/Agent 再核主要结论和换算。没有完整自动核验则说明覆盖范围，不声称全部通过。
3. 摘要—正文—表格—结论是否一致；重要反证/局限、筛选和多重检验是否披露；文献论断是否有原文支持。
4. 报告层级与索引、附件、复跑命令和各导出格式是否完整可用。

审核结果记录通过项、问题、未检查项和证据位置；发现数字或解释错误应修正源表/代码或论断并重新生成依赖报告，保留旧版本。未解决问题显著标注为草稿/证据不足；可交付阶段成果，但不能宣称已通过完整审核。无 subagent 时注明自审，不伪装独立审核。出版级格式不等于因果识别或投稿就绪。
